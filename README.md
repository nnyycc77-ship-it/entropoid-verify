# entropoid-verify

The public website of Entropoid, served at https://verify.entropoid.com by GitHub Pages.

Entropoid builds verification services where every claim carries its quoted source:
RigGrade (GPU rig grading), Verdict Desk (verdicts on work postings) and a citation
checker for delivered reports.

## Layout

- `index.html`: the whole site, one static page, no build step and no external scripts.
  Fonts load from Google Fonts; everything else is inline.
- `CNAME`: the custom domain for GitHub Pages.
- `.nojekyll`: tells Pages to serve the files as they are.

## Editing

Edit `index.html` and push to `main`. Pages redeploys within a minute or two.

The site states no revenue, track-record or customer figures, and no personal details.
Keep it that way: product facts and method only.
